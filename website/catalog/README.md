# Template catalog

Every `.json` file in this folder is a template that people can add from **+ Add from templates**.  

These templates are made by Kaaiman12, the creator of this project, but you can add your own ones if you wish, just use the following template (category, description, country and checklist are optional):  

```json
{
  "id": "visit-norway",
  "title": "Visit Norway",
  "category": "Locations",
  "description": "Fjords, mountains and the long coastline.",
  "country": "no",
  "checklist": ["Oslo", "Bergen", "Tromsø", "Lofoten"]
}
```
